AI Investment Desk: Agent Architecture

System Overview

The system uses a LangGraph state machine to orchestrate 5 specialist agents. Each agent queries specific data sources in parallel, and synthesis combines findings when needed.

Specialist Agents

1. Portfolio Agent Holdings, value, gain/loss

Queries Holdings table + Prices. Returns what you own and current portfolio value.

2. Valuation Agent P/E, margins, free cash flow

Queries SEC data from CompanyFinancialFact table. Answers "is this expensive?"

3. Risk Agent Concentration, position weights

Analyzes holdings + prices. Calculates what % of portfolio each position is.

4. Market Research Agent News, sentiment, company research

Queries CompanyNews table. Returns headlines and detailed company research.

5. Macro Agent VIX, interest rates, inflation

Queries MacroIndicator table (FRED data). Provides market context.

Routing Decision

The Router uses an LLM with ROUTING_PROMPT to understand the user's question and decide which agents to run.

Example routing:
"What do I own?" → Portfolio only
"What's my P/E?" → Valuation only
"Am I concentrated?" → Risk only
"Give me all metrics" → Portfolio + Valuation + Risk + Market Research + Macro

Execution Flow

1. Route (LLM decides agents)

Router analyzes the question and returns list of agent names to run.

2. Execute (Parallel)

All selected agents run at the same time with fresh database sessions to avoid race conditions.

Example timing: Portfolio (28ms) + Valuation (42ms) + Risk (35ms) → Total: ~42ms (not 105ms, because parallel)

3. Conditional Branch

System checks: Was only the Portfolio agent selected?

  • Yes: Go to direct_portfolio node (fast, no synthesis needed)
  • No: Go to synthesize node (combine multi-agent findings)

4. Response

Either return the portfolio answer directly, or use Synthesis Agent to combine all findings into one coherent response with source attribution.

Data Flow

Key Characteristics

Parallel Execution: All selected agents run at the same time, not sequentially. Fresh database session per agent prevents race conditions.
LLM-Based Routing: Not keyword matching. Router sends question to LLM with descriptions of each agent, LLM decides which to run.
Source Attribution: Every finding includes credibility score, evidence level, confidence, and data source for transparency.
Selective Synthesis: Portfolio-only questions skip synthesis (fast), multi-agent questions use Synthesis Agent to combine findings.

Current Issues (Q4 & Q5)

Root Cause: The direct_portfolio node (line 125-191 in assistant_workflow.py) doesn't parse the user question for specific holdings. It always returns complete portfolio.
